# Create Horizon: общий план переноса

Цель — опыт **Create 6.0.10**, закреплённого в `compatibility.json`: одинаковые
механизмы, взаимодействия, данные, интерфейсы, звук и эффекты. Rust-код может иметь
другую внутреннюю структуру. Совпадение моделей или отдельных формул само по себе
не означает, что подсистема завершена. Java JAR дополнений здесь не исполняются.

Обозначения: `[x]` — проверенный ограниченный пункт; `[ ]` — предстоит либо
перенесён частично. У большой подсистемы галочка появится только после проверки
всего перечисленного поведения. Текущие подробные границы — в
[COMPATIBILITY.md](COMPATIBILITY.md), доказательства — в [VALIDATION.md](VALIDATION.md).
Процент готовности — только грубая оценка, не результат подсчёта этих строк.

Следующий этап разрабатывается в `stage/parity-06`. Промежуточная сборка и
подтверждённые различия описаны в [DEVELOPMENT_06.md](DEVELOPMENT_06.md);
таблица ниже сохраняет границу последнего выпущенного этапа 0.5.

| Подсистема | Состояние на проверенной версии 0.5 | Следующий критерий |
|---|---|---|
| Установка и ресурсы | Рабочий native pipeline, локальный JAR | Проверить следующий выпуск тем же путём |
| Кинетическая сеть | Основные валы, шестерни, редукторы и нагрузка | Завершить эффекты, диагностику и сложные соединения |
| Обработка предметов | Депо, пресс, жернов, поток | Точное отображение и полноценные фабричные цепочки |
| Генерация вращения | Творческий мотор, рукоятка, водяные колёса | Остальные источники, регулирование и энергетика |
| UI и визуальная обратная связь | Модели импортируются; UI и эффекты частичны | Сравнение с настоящим Java-клиентом |
| Схематики | Перенос в работе | Строгая creative-вставка общих `.nbt` |
| Транспорт и автоматизация | Воронки и базовый IO | Ленты, воронки Create, туннели, манипуляторы |
| Смешивание и нагрев | Предстоит | Basin, mixer, blaze burner, рецепты |
| Жидкости | Предстоит | Сети труб, насосы, ёмкости, обработка |
| Движущиеся конструкции | Предстоит | Общий сборщик, трансформации, коллизии и акторы |
| Поезда и логистика | Предстоит | Пути, составы, расписания, грузы |
| Ponder и руководства | Предстоит | Исходные сцены, управление и оформление |
| Дополнения | Архитектурное требование | Публичные Rust-контракты; затем Sable и Aeronautics |

движущиеся конструкции → жидкости/поезда/остальные системы → Sable/Aeronautics.
Каждый завершённый этап получает сборку, доказательства проверки и отдельный обзорный мир.
