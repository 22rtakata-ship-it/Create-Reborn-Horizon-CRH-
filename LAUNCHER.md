# Запуск в официальном Horizon Launcher

На машине разработки уже создан и запущен отдельный инстанс **Create Prototype**.
В лаунчере выберите его слева и нажмите **Play**. Мир первой проверки называется
**CreateDemo**. У обычного инстанса **Horizon** осталась прежняя Nightly.

Сейчас используется штатная возможность лаунчера **Import a game build**:
проверенный `target/fast/horizon-client` установлен отдельной версией с пометкой
**Imported**, а контентный архив `dist/create-content-0.1.0.hmod` скопирован в
`horizon-mods/create.hmod` нового инстанса. В его `horizon-mods.txt` включён
`mod.create:true`. Исходная Nightly не заменена. Это разработческая сборка без
звука и поддержки контроллеров.

## Почему пока нужен импорт сборки

Нативные моды Horizon обычно собираются вместе с отдельной копией игры: лаунчер
сам скачивает Rust, применяет mixins к исходникам и компилирует клиент. Это
предусмотренный способ работы `.hnmod`, а не необходимость постоянно поддерживать
отдельный форк игрового движка.

В закреплённом Mixins есть ошибка: стандартный Rust-атрибут `recursion_limit`
считается неизвестным процедурным макросом. Наши скрипты уже обходят её локальной
поправкой, поэтому полученный клиент работает. Неизменённый официальный лаунчер
на этих версиях не может повторить сборку сам. Исправление отправлено в
[horizon-rust/horizon-mixins, PR #26](https://github.com/horizon-rust/horizon-mixins/pull/26);
игровая логика Horizon для него не меняется.

После принятия исправления нужно закрепить новый официальный коммит Mixins в
архивах Create и повторить проверку через лаунчер. Старый архив автоматически
обновлённый инструмент не получит: его версии намеренно закреплены.

## GitHub и каталог

Исходники: <https://github.com/Delete228/create-horizon>.

**Add from GitHub** умеет устанавливать нативные исходники или `.hnmod` из GitHub.
Это не обходит указанную ошибку и само по себе не устанавливает наш отдельный
контентный архив. Успешно скачать код ещё не означает получить все блоки мода.

Публикация в общем каталоге — отдельный процесс проверки сопровождающими.
Текущее состояние и оставшиеся требования находятся в
[REGISTRY_READINESS.md](REGISTRY_READINESS.md). Исходники Create имеют пометку
неофициального прототипа; одобрение Horizon или готовность полного Create не заявлены.

Официальные руководства:
[нативная сборка и импорт из GitHub](https://github.com/horizon-rust/horizon/blob/main/docs/native-mods.md),
[import-build](https://github.com/horizon-rust/horizon/blob/main/docs/launcher-commands.md#horizon-launcher-import-build),
[установка контента вручную](https://github.com/horizon-rust/horizon/blob/main/docs/mods.md#playing-with-mods).
