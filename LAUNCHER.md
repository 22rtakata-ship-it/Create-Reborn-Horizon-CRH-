## Новый instance

1. В официальном Horizon Launcher нажмите **+** рядом с **Instances** и создайте
   обычный Horizon instance, например **Create Native**. Выберите его слева.
2. Подготовьте обычную версию Horizon кнопкой Play, если ресурсы Minecraft 26.3
   ещё не подготовлены. Можно использовать уже установленную подготовленную версию.
3. Откройте **Mods → Add from GitHub**, вставьте
   `https://github.com/Delete228/create-horizon` и установите мод `create`.
   Лаунчер покажет точный коммит и запрос доверия к нативному коду.
4. Запустите сборку нативных модов в лаунчере. Первая сборка скачивает компилятор,
   исходники и зависимости; повторные используют кэш. Получается отдельная
   версия `native-fc02103-…`, которую лаунчер закрепляет за выбранным instance.
5. Откройте папку instance и положите один оригинальный JAR **Create 6.0.10,
   NeoForge, Minecraft 1.21.1** в `horizon-mods/create-resources/`.
   [Поддерживаемый файл и контрольная сумма](ASSETS.md).
6. Нажмите **Play**. Мод сам подготавливает свой публичный контент и импортирует
   оригинальные ресурсы. Отдельный контентный архив копировать не нужно.

Текстуры и модели не включаются в GitHub-пакет. Без поддерживаемого JAR игра
использует временные модели и сообщает причину в логе. Java-код JAR не запускается.

Если сборка или instance добавлены через консоль при открытом окне лаунчера,
перезапустите это окно перед визуальной проверкой: текущая версия интерфейса может
сохранять старый список установленных сборок. Проверяйте выбранный instance и
пометку Native на странице запуска.

## Сборка через консоль

Нужны установленный официальный лаунчер и уже созданный instance. Сборка
установленного из GitHub мода не требует соседних репозиториев или нашего Rust:

```sh
horizon-launcher mods add-github https://github.com/Delete228/create-horizon --instance "Create Native" --trust-native-code
horizon-launcher native-build --instance "Create Native" --profile dev --trust-native-code
```

На macOS бинарник находится в
`/Applications/Horizon.app/Contents/MacOS/horizon-launcher` и может отсутствовать
в PATH. Из рабочей копии этого репозитория те же команды вызывает помощник:

```sh
python3 tools/launcher.py --instance "Create Native" --github https://github.com/Delete228/create-horizon
```

Повторная сборка: та же команда без `--github`. Для изменений ещё не опубликованной
рабочей копии используйте `--source`; Create должен быть установлен и включён в этом
instance. Помощник передаёт лаунчеру только публичный нативный пакет, без `.git`,
кэшей, JAR или подготовленных Minecraft-ресурсов.

`dev` выбран для частых итераций: зависимости оптимизированы, игровой код собирается
быстрее. `--profile performance` включает оптимизацию игрового кода; первая такая
сборка дольше. Это обычные профили лаунчера. Звук и контроллеры штатной сборкой
не отключаются; тестовые запуски используют `HORIZON_NO_AUDIO=1`.

## Публичный контент внутри нативного пакета

`mixins/create/data/content.json` содержит только наши JSON-модели, переведённые
объявления блоков/предметов, рецепты, переводы и манифест. Документированный
`native_data!` включает этот файл в клиент. Перед штатной загрузкой контента мод
подготавливает `horizon-mods/.create-native-content/` в своём instance. Существующие
файлы других модов и настройки включения не меняются. Папка обновляется и
восстанавливается из текущей сборки; вручную редактировать её не следует.

Один флаг `mod.create` включает нативный мод и его контент. Исходный нативный архив,
оригинальный JAR и импортированный ресурсный кэш — отдельные файлы с разным назначением.
Старый **Create Prototype** использует Imported-сборку; он оставлен для сравнения.

## Визуальная проверка этой итерации

- Выбран **Create Review 0.2**, запускается Native-сборка `0554886ea08b`.
- Поставьте вал, глядя горизонтально вдоль X/Z и сверху вниз; проверьте
  подстройку к соседнему валу и размещение с Shift. Аналогично проверьте шестерни.
- Кликните свечой или листом по верхней стороне свободного депо: вся стопка
  переходит на него без меню. Пустая рука забирает, другой предмет заменяет стопку.
  При Shift с предметом депо пропускает действие, как ванильные блоки.
- Проверьте оригинальные модели в мире, инвентаре и руке. Названия на русском
  и английском берутся из JAR; импортируются все исходные языки.
- Проверьте фабрику и повторное открытие нового мира после сохранения.

Полная точность анимаций, звуки, вода, остальные механизмы и полный Java-формат
данных ещё не заявляются. Границы — в [COMPATIBILITY.md](COMPATIBILITY.md).
Все замечания записываются независимо от запланированного этапа.
