# Mechanics

Retain the existing pressing, milling, crushing, fan, basin, crafting and transport algorithms and their regression tests. Data recipes live in content and are compiled by the existing native adapters. A registered recipe or static test does not establish a complete automated survival line.

The current crusher adapter is bounded (not every orientation, entity interaction or receiver). Fan media, recipes and item components need the real-world fixtures retained under tools. Use upstream docs and reborn/feature-matrix.md for limitations. Mechanics' mounted Deployer and shared particle presentation use the optional contraptions feature; disabling it excludes those modules.
