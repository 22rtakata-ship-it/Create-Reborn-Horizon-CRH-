# Contraptions

The fork retains read-only assembly, transforms, bearings/windmills, piston/pulley/gantry, storage and tool actors. create-contraptions depends only on create-core, so the mechanics module is not required for these algorithms.

World capture/restoration, attached data and save/reload remain native adapters, with documented single chunk-column limits. Never infer safe arbitrary moving structures from algorithm tests. See reborn/upstream-contraptions.md for the preserved guide and reborn/feature-matrix.md for evidence levels.
